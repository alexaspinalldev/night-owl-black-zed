# Night Owl Black for Zed

<img width="1822" height="1185" alt="Screenshot 2026-10-16 at 17 00 54" src="https://github.com/user-attachments/assets/62230ae2-e454-4274-a78e-d77f8b5dc3e7" />

A port of [Night Owl Black](https://github.com/thedavej/night-owl-black) (VS Code) for [Zed](https://zed.dev).

Pure black editor background (`#000000`), Night Owl syntax colours, and two variants:

- **Night Owl Black** — italics for comments, keywords, and attributes
- **Night Owl Black (No Italics)** — same palette without italics

Indent / bracket accents use a violet → mint ramp tuned for Zed’s fixed opacity on indent backgrounds.

## Install (dev)

1. Clone this repo
2. In Zed: `zed: install dev extension` and select the clone folder
3. Theme selector → **Night Owl Black**

## Install (after publish)

Open `zed: extensions`, search for **Night Owl Black Theme**, install.
